# Системные правила работы на CTF (Кубок России 2026, платформа biba)

## 0. Контекст
Перед любым взаимодействием с платформой — прочитай skill `PLATFORM.md` (biba-platform).
Он описывает полный API: эндпоинты, форматы запросов, типы инстансов (static/http/tcp/ssh).

## 1. Токен сессии
- Токен дам тебе в чате вручную (вставлен из `localStorage.getItem('session.token')`).
- Никогда не записывай токен в файлы, не логируй, не печатай его обратно в чат/отчёты.
- Используй только в теле запросов согласно формату из skill.
- Если любой запрос вернул `401` — останови работу и попроси у меня новый токен.

## 2. Spawn / Destroy инстансов — ТОЛЬКО через UI
- Никогда не вызывай `/api/tasks/spawn` и `/api/tasks/destroy` напрямую — это запрещено даже если кажется, что получится (капча всё равно заблокирует).
- Когда нужен инстанс для таска — скажи мне явно: "нужен спавн для task_id: X", и жди.
- После моего подтверждения — поллинг `/api/users/profile` каждые 2–3 секунды (не чаще), пока не появится инстанс с нужным `task_id`. Если за ~60 секунд не появился — сообщи мне, не зацикливайся молча.
- Endpoint и token приходят в ответе `/api/users/profile` автоматически — бери их оттуда, вручную IP/порт не нужны.
- После решения таска — скажи мне, что можно уничтожить инстанс (я сделаю через UI).

## 3. Продление инстанса
- Если `expire_at` подходит близко, а таск ещё не решён — сам вызови `/api/tasks/extend`. Не жди, пока инстанс протухнет.

## 4. Приоритизация тасков
При получении `/platform/tasks`:
1. Выведи таблицу: id, title, tags, type, min_price, max_price.
2. Раздели на две группы по пригодности для автоматического решения:

**Высокая пригодность (решаем в первую очередь):**
crypto с понятной схемой, web (SQLi/SSTI/IDOR/auth bypass), pwn с базовыми протекциями, forensics с чёткими артефактами (pcap/memory dump/стандартная стеганография), reverse с несложной обфускацией.

**Низкая пригодность (не трать время, сразу сообщи мне):**
OSINT, misc с творческой/нестандартной логикой, задачи на знание локальных реалий/мемов/событий, нестандартная кастомная стеганография.

3. Static-таски без нужды в спавне — бери в работу сразу, не дожидаясь моих действий.
4. Среди "высокой пригодности" сортируй по убыванию max_price — дороже обычно значит меньше решивших = больше смысла успеть раньше.

## 5. Перед решением каждого таска
Дай короткую оценку (1–2 предложения): сложность 1–5, предполагаемый подход. Не пиши сразу эксплойт на 20 минут вслепую — сначала короткий чек со мной, если не уверен в направлении.

## 6. Флаги
- Никогда не сабмить флаг, если нет уверенности, что он правильный. Не брутфорсить угадыванием.
- Если `/api/tasks/submit` вернул `invalid flag` — не повторяй тот же флаг, продолжай искать.
- Если `task already solved` — сообщи и остановись по этому таску.

## 7. После КАЖДОГО успешного сабмита
1. Допиши запись в `tasks/solved.md` (создай, если файла нет), не затирая предыдущие записи:
   ```
   ## <title> (<task_id>)
   - Категория: <tags>
   - Флаг: ctf{...}
   - Подход: <1-2 предложения>
   - Время: <timestamp>
   ```
2. Сохрани рабочий скрипт/эксплойт в `tasks/<category>/<task_id>/solve.py`.

## 8. Общее
- Если застрял на тасков дольше ~15–20 минут без прогресса — сообщи мне и предложи переключиться на другой, не сиди в одном направлении молча.
- Если категория/формат таска незнакомы — спроси у меня, прежде чем тратить время.
